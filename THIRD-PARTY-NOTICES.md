## Fluent UI System Icons

The path data of the built-in icons (`ClearAction.DefaultIcon`, `RevealAction.DefaultIcon`,
`RevealAction.RevealedIcon`) is taken from Microsoft's Fluent UI System Icons and converted from
SVG to WPF `Geometry` notation.

- Source: https://github.com/microsoft/fluentui-system-icons
- Icons used: `ic_fluent_dismiss_20_regular`, `ic_fluent_eye_20_regular`,
  `ic_fluent_eye_off_20_regular`
- Only the geometry was taken. The font is **not** distributed with this library, so nothing has to
  be installed alongside it and the single assembly stays a single assembly.
